# Portfolio

Personal site (static HTML/CSS/JS). Live site: **https://akhilsantha7.github.io/Portfolio/**

## Deploy

- Source lives in **`portfolio/`** (`index.html`, etc.).
- GitHub Actions publishes that folder to **GitHub Pages** (see `.github/workflows/github-pages.yml`).
- After the first push: repo **Settings → Pages →** set source to **GitHub Actions**.

More detail: [GITHUB_PAGES.md](./GITHUB_PAGES.md)

**Video files:** `*.mp4` uses **Git LFS** — see [GIT_LFS.md](./GIT_LFS.md).
